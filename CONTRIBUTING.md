# Contributing to TurboCraft Launcher

First of all, thank you for your interest in contributing to **TurboCraft Launcher**.

We welcome bug fixes, new features, documentation improvements, translations, performance optimizations, and UI enhancements.

---

## Before You Start

- Read the README before making changes.
- Discuss large features by opening a GitHub Issue first.
- Follow the project's coding style.
- Keep pull requests focused on a single change.
- By contributing, you agree that your contributions will be licensed under **GPL-3.0**.

---

# Development Requirements

- Android Studio Bumblebee or newer
- Android SDK 35
- Minimum SDK 26
- JDK 11
- Git

---

# Getting Started

Clone your fork:

```bash
git clone https://github.com/YOUR_USERNAME/TurboCraft-Launcher.git
cd TurboCraft-Launcher
```

Open the project in Android Studio and allow Gradle to sync.

---

# Branch Naming

Use descriptive branch names.

Examples:

```
feature/video-settings
feature/account-manager

fix/crash-on-launch
fix/rendering-bug

docs/update-readme

refactor/java-runtime
```

---

# Commit Messages

Please write clear commit messages.

Examples:

```
[FEAT] Add offline account improvements

[FIX] Resolve launcher startup crash

[PERF] Optimize renderer loading

[DOCS] Update installation guide
```

---

# Pull Requests

Before opening a Pull Request:

- Make sure the project builds successfully.
- Test your changes.
- Remove debug code.
- Update documentation if necessary.

Please include:

- What changed
- Why it changed
- Screenshots (if UI related)

---

# Coding Guidelines

- Follow Kotlin coding conventions.
- Prefer `val` over `var`.
- Keep code readable.
- Avoid unnecessary complexity.
- Add comments only when required.

---

# Reporting Bugs

When reporting a bug, please include:

- Device model
- Android version
- Launcher version
- Steps to reproduce
- Latest log (if available)

---

# Feature Requests

Before requesting a feature:

- Check existing Issues.
- Explain why the feature is useful.
- Describe the expected behavior.
